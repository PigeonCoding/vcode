1. Mental model & toolchain

IL is higher-level than machine assembly: it smooths out hardware irregularities and offers an infinite number of temporaries, so the frontend can focus on language design instead of registers. A compilation unit is a text file of definitions; QBE turns it into assembly for one target (amd64_sysv by default here).

$ qbe prog.ssa -o prog.s && cc prog.s -o prog
# or from Odin: qbe.compile_file("prog.ssa", "prog.s")

2. Files, sigils, comments, spacing

  • A file is a sequence of definitions. Order matters only for types (define before use); data and functions are mutually recursive, even across files — no forward declarations needed.
  • Comments start with # and run to end of line.
  • Tokens are separated by spaces/tabs; newlines also count as spaces inside data and type definitions. Spacing may be omitted next to symbols like ,, =, {.
SigilMeaning
:user-defined aggregate type
$global (a pointer to it)
%function-scope temporary
@block label

3. Types & subtyping

Four base types — the only types temporaries can have. There are no pointer types; use an integer wide enough for addresses (l on 64-bit).

TypeMeaning
wword, 32-bit integer
llong, 64-bit integer (pointers on 64-bit targets)
ssingle, 32-bit float (IEEE 754)
ddouble, 64-bit float (IEEE 754)

Two extended types for data/aggregates: b (byte, 8-bit) and h (half word, 16-bit).

Subtyping (integers only): an l value may be used where a w is expected (low 32 bits) — but not the reverse, since w→l is ambiguous (sign vs zero extension; use extsw/extuw).

%x =w sub -1, 0
%y =w sub 4294967295, 0   # same value: 32-bit context keeps low bits

4. Constants and vals

Constants are untyped 64-bit blobs; context decides which bits matter.

CONST := [-]NUMBER | s_FP | d_FP | $IDENT
VAL   := CONST | %IDENT            # plus thread/extern forms in bodies
  • Integers: decimal, two's complement. Floats: s_/d_ + scientific notation (d_0.5, d_-1).
  • $sym: a global's address (resolved by the linker).
  • Function bodies only: thread $tls (TLS value), extern $sym (GOT/PLT, for PIE/PIC), extern thread $sym (initial-exec TLS).

5. Linkage

export function w $main() { ... }   # visible to other files / C callers
thread data $i = { w 42 }           # thread-local storage (data only)
section ".init_array"
data $.init.f = { l $f }            # custom linker section

export = visible outside the file (required for C-called functions). thread (data only) = per-thread copy, accessed via thread $i. Zeroed data lands in BSS automatically.

6. Aggregate types (for C structs)

type :fourfloats = { s, s, d, d }
type :abyteandmanywords = { b, w 100 }  # array shorthand; trailing comma OK
type :cryptovector = align 16 { w 4 }   # explicit alignment (else: max member)
type :un9 = { { b } { s } }             # union: max size of variants
type :opaque = align 16 { 32 }          # unknown layout: align + size required

Aggregates are not first-class: passed/returned by pointer. Load members out explicitly:

type :one = { w }

function w $getone(:one %p) {
@start
	%val =w loadw %p
	ret %val
}

7. Data

data $a = { w 1 2 3, b 0 }   # three words 1,2,3 then a zero byte
data $b = { z 1000 }         # 1000 zero bytes (padding / big arrays)
data $c = { l -1, l $c }     # all-ones long, then a pointer to itself
data $str = { b "hello world", b 0 }   # strings are byte sequences + NUL

Fields are packed (the frontend emits padding); a type letter starts a run of one or more items of that size; z N is N zero bytes.

8. Functions

function [RETTY] $name(ABITY %arg, ..., [env %e,] [...]) {
	BLOCK+
}
  • Type before the name = return type; omitted = returns nothing.
  • Sub-word params sb ub sh uh (C char/short): only low N bits set, temporaries are w — extend before use; sub-word returns need no extension. 
    function w $addbyte(w %a, sb %b) {
@start
	%bw =w extsb %b
	%val =w add %a, %bw
	ret %val
}
  • env %e (first param, l): closure environment, invisible to C — export function w $add(env %e, w %a, w %b) is called from C as int add(int, int) (verified below).
  • Variadic: param list ends with ...; extras are read with vastart/vaarg. Callers separate fixed and extra args with ....

9. Blocks and jumps

A function is a serialized control-flow graph: label, straight-line code, exactly one jump. Two structural rules:

  1. The first block must never be a jump target (add an empty prelude if you need to jump to the top).
  2. A missing jump to the next block is auto-inserted (fall-through).
JUMP := 'jmp' @dst | 'jnz' VAL, @ifnz, @ifz | 'ret' [VAL] | 'hlt'

jnz tests a word (a long works — low 32 bits are tested). ret [VAL] must match the return type. hlt ends the program (for unreachable code).

10. Instruction reference

Three-address code: %r =TYPE op arg1, arg2. Reading type strings: T=wlsd, I=wl, F=sd, m=pointer-sized int (l on 64-bit). X(Y,Z) = return X, args Y,Z.

Arithmetic and bits

Comparisons — the c… scheme

Name = c + relation + operand suffix; result is 1/0 as word or long. Integer relations: eq ne sle slt sge sgt ule ult uge ugt; float: eq ne le lt ge gt o uo (o = ordered/no NaN, uo = unordered/some NaN).

Cast and copy

OpType stringMeaning
castwlsd(sdwl)bit-identical reinterpret int↔float of same width
copyT(T)plain move

Calls

[%r =ABITY] call $fn(ARG, ...)
ARG := ABITY VAL | env VAL | ...

Calls carry every argument's type (for the C ABI); aggregates go by pointer; sub-word args need no extension; a return temporary is required whenever the callee returns one. Variadic calls put ... between fixed and extra arguments.

Variadic callees

vastart (m) initializes a vararg list (conservatively alloc8 32); vaarg T(mmmm) fetches the next base-typed argument (effectful — each call advances). Sizes per target: amd64_sysv 24, amd64_win 8, arm64 32, rv64 8 (all align 8).

11. Phi — and why you may skip it

%y =w phi @ift 1, @iff 2 picks a value by predecessor block. But two easier paths exist:

  1. Memory variables: keep source variables in alloc4/8 slots with loads/stores (what LLVM frontends do).
  2. Non-SSA code: QBE repairs it itself — reassigning a temporary without phi compiles correctly (the countdown loop below relies on this).

Use phi only when the SSA invariants hold — and double check predecessor lists: a phi in a loop header names the blocks that jump to it (e.g. @start and @body below, not the header itself unless the back edge targets it directly).

12. Examples (all verified)

Assembled with the vendored QBE; runnable ones were linked with cc and executed — observed outputs are shown. Small hand-written programs first, then verbatim programs from libs/qbe/test/*.ssa.

Hello world (data + call + return)

data $fmt = { b "hello world", b 0 }

export function w $main() {
@start
	%r =w call $puts(l $fmt)
	ret 0
}
$ qbe hello.ssa -o hello.s && cc hello.s -o hello && ./hello
hello world

Countdown loop (fall-through + non-SSA reassignment)

export function w $sum100() {
@start
	%x =w copy 100
	%s =w copy 0
@loop
	%s =w add %s, %x
	%x =w sub %x, 1
	jnz %x, @loop, @end
@end
	ret %s           # -> 5050

Verified: returns 5050 when called from C.

Max of two (branches + phi)

export function w $max2(w %a, w %b) {
@entry
	%c =w csltw %a, %b
	jnz %c, @less, @ge
@less
	jmp @join
@ge
	jmp @join
@join
	%m =w phi @less %b, @ge %a
	ret %m
}

Verified: max2(3,7)=7, max2(9,2)=9.

Sum 1..n (loop with parameters + phi)

export function w $sumrange(w %n) {
@start
@loop
	%i =w phi @start 0, @body %i1
	%s =w phi @start 0, @body %s1
	%c =w csltw %i, %n
	jnz %c, @body, @end
@body
	%i1 =w add %i, 1
	%s1 =w add %s, %i1
	jmp @loop
@end
	ret %s
}

Verified: sumrange(10)=55. Note the phi predecessors are @start and @body — the blocks that actually jump to @loop.

Factorial (recursion + calls)

export function w $fact(w %n) {
@start
	%c =w cslew %n, 1
	jnz %c, @base, @rec
@base
	ret 1
@rec
	%n1 =w sub %n, 1
	%r =w call $fact(w %n1)
	%p =w mul %n, %r
	ret %p
}

Verified: fact(5)=120, fact(0)=1.

Euclid's GCD (two-predecessor phi)

export function w $gcd(w %a0, w %b0) {
@start
@loop
	%a =w phi @start %a0, @loop %r
	%b =w phi @start %b0, @loop %a
	%r =w rem %b, %a
	jnz %r, @loop, @end
@end
	ret %a
}

Verified: gcd(380,747)=1. Watch the update direction: %a takes %r, %b takes old %a — swapping them returns 367 (caught by running).

String length (pointer walk + bytes)

export function l $str_len(l %s) {
@start
@loop
	%p =l phi @start %s, @loop %p1
	%i =l phi @start 0, @loop %i1
	%c =w loadub %p
	%p1 =l add %p, 1
	%i1 =l add %i, 1
	jnz %c, @loop, @end
@end
	%len =l sub %i1, 1
	ret %len
}

Verified: str_len("hello")=5, str_len("")=0.

Float arithmetic

export function d $fma2(d %x) {
@start
	%t =d mul %x, d_2
	%r =d add %t, d_0.5
	ret %r            # fma2(3.0) = 6.5

Verified by running.

Stack memory and loads

export function w $total() {
@start
	%A0 =l alloc4 8      # 8-byte stack array (2 words)
	%A1 =l add %A0, 4
	storew 43,  %A0
	storew 255, %A1
	%v1 =w loadw  %A0    # 43
	%v2 =w loadsb %A1    # 255 as signed byte = -1
	%v3 =w add %v1, %v2  # 42
	ret %v3
}

Verified: returns 42.

Bit-cast negation (cast)

export function s $neg(s %f) {
@start
	%b0 =w cast %f
	%b1 =w xor 2147483648, %b0   # flip msb
	%rs =s cast %b1
	ret %rs
}

Verified: neg(1.5)=-1.5.

Closure environment (invisible to C)

Array maximum (from test/max.ssa — data + scan)

data $arr = { b 10, b -60, b 10, b 100, b 200, b 0 }

export
function $test() {
@start
@loop
	%max =w phi @start -1, @new %byt, @old %max
	%loc =l phi @start $arr,  @new %loc1, @old %loc1
	%byt =w loadub %loc
	%loc1 =l add 1, %loc
	jnz %byt, @iter, @end
@iter
	%cmp =w cslew %max, %byt
	jnz %cmp, @new, @old
@new
	jmp @loop
@old
	jmp @loop
@end
	storew %max, $a
	ret
}

Verified: stores 200 into $a (NUL-terminated byte array, unsigned compare).

13. Backends & vcode integration

One IL file compiles for any of six targets (qbe -t): amd64_sysv (default) · amd64_apple · amd64_win · arm64 · arm64_apple · rv64.

From Odin (see libs/qbe/qbe.odin, qbe_lib.h):

import qbe "../libs/qbe"

qbe.compile_text(il_source, "out.s")              // "" = default target
qbe.compile_text(il_source, "out.s", qbe.TARGET_ARM64)
qbe.compile_file("prog.ssa", "prog.s", qbe.TARGET_RV64)

b: strings.Builder
strings.builder_init(&b, context.allocator)
defer strings.builder_destroy(&b)
qbe.compile_to_builder(il_source, &b)           // appends asm, no temp file
asm, _ := qbe.compile_to_string(il_source)   // fresh string version

qbe.default_target() // -> "amd64_sysv" on this machine

Caveats for frontend authors: malformed IL aborts the process (QBE's err() calls exit(), like the CLI exiting 1) — only feed it generated IL. Struct layout/padding is the frontend's job.
