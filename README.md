# A Small Compiled Programming Language

## Requirements
- `odin`
- `gcc` or `clang` in your path (alternatively set the -cc flags ex: ./vcode -cc /your/path/compiler )

## How to build
```console
$ odin run ./builder
$ odin run ./test # to build all the examples
$ ./build/vcode -o examples/hello examples/hello.vc
```
